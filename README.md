## Engineering Principles

> **Build for reliability. Keep systems understandable. Measure before optimizing.**

A few principles I try to follow:

- Prefer simple architecture over unnecessary complexity.
- Design APIs around predictable contracts.
- Treat database design as part of application architecture.
- Optimize based on measurements, not assumptions.
- Build systems that are observable and maintainable.
- Automate repetitive engineering workflows.
- Take ownership beyond writing code.
- Think about the product, not just the implementation.
